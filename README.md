## Selected work

| Project | What it does | Stack | Result |
| :--- | :--- | :--- | :--- |
| **[Olinea](https://sithunyein.com/work/olinea)** | USDC vault that releases funds only when an SLH-DSA-SHA2-128s signature verifies on-chain. No owner, no admin, no upgrade path. | Arc mainnet · Solidity | Arc Microgrants winner |
| **[Equxi](https://sithunyein.com/work/equxi)** | Agent operators lock a bond, rules live on-chain, misbehavior gets slashed and victims compensated. | Solana · Rust | Superteam grant |
| **[Witness](https://sithunyein.com/work/witness)** | A human approves one exact agent action with their device passkey; the contract rejects anything over the spending ceiling. | Mezo · Monad · P-256/WebAuthn | 41 contract tests |
| **[Meter](https://sithunyein.com/work/meter)** | Pay-per-call API gateway: any HTTP endpoint charges USDC per request, no API keys or accounts. | Arc mainnet · Foundry | 22 tests, per-receipt replay protection |
| **[bill402](https://sithunyein.com/work/bill402)** | Create an invoice, get an x402 URL, settle in USDC on Base. No signup. | Base · x402 | Live |
| **[Susunaku](https://sithunyein.com/work/susunaku)** | Savings circles where members pay each other wallet to wallet. No custodian, no pooled pot. | Stellar · USDC | Pollar 3rd place |
